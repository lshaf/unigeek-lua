# LED Resistor

Given the supply voltage, the LED's forward voltage, and the target current in mA, computes the series resistor needed, the nearest E12 standard value at or above it, the power it dissipates, and the actual current you'll get with that standard resistor.

## Controls

| Button | Action |
|--------|--------|
| OK | run another calculation |
| BACK | exit |

In-memory only.
