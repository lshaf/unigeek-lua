# Dice Roller

Pick a die type, roll it, see the result big in the centre with a short rolling animation. The most recent rolls collect in a strip at the bottom.

## Controls

| Button | Action |
|--------|--------|
| UP | previous die type (cycles) |
| DOWN | next die type (cycles) |
| OK | roll the current die |
| BACK | exit (also aborts an in-progress roll animation) |
