# Resistor Calculator

Dial in the colour of each band and read off the resistance and tolerance. Two significant-digit bands, a multiplier band, and a tolerance band are drawn on a resistor body; the active band is marked with an arrow.

## Controls

| Button | Action |
|--------|--------|
| OK | select the next band (digit1 -> digit2 -> mult -> tol -> ...) |
| UP | previous colour for the active band |
| DOWN | next colour for the active band |
| BACK | exit |

In-memory only.
