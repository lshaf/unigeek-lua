# Bitwise Playground

Pick an operation, enter operand A (and B where it applies), and see A, B and the result side by side in decimal, hex and 16-bit binary (grouped in nibbles). Lua 5.1 has no bitwise operators, so every op is done by hand on the bits — all values are treated as unsigned 16-bit (0..65535).

## Controls

| Button | Action |
|--------|--------|
| OK | run another operation |
| BACK | exit |

In-memory only.
