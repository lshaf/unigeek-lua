# Reaction Timer

A coloured panel guides the user through each attempt:   blue READY?  → press OK to start   yellow WAIT  → hold; do NOT press until green   green GO!    → press OK as fast as you can   teal RESULT  → shows reaction in ms (and updates best)   red TOO SOON → pressed during the wait — retry

## Controls

| Button | Action |
|--------|--------|
| OK | start / acknowledge result / retry after a fault |
| BACK | exit |

Best time persists to /unigeek/games/reaction.txt.
