# Stacker

A coloured block slides left and right along the top of the screen. Press OK to drop it on the stack below — any overhang past the previous block is trimmed off, so the tower narrows over time.

Endless climb: when the tower reaches the ceiling the whole stack scrolls down one block to make room, so you keep stacking the same width forever — no wipe, no reset. Each scroll counts as a level: the slider starts faster and the in-level speed cap lifts a notch, so timing gets tighter the higher you climb. The run ends only when a drop misses.

## Controls

| Button | Action |
|--------|--------|
| OK | drop the moving block |
| BACK | exit (also dismisses Game Over) |

High score persists to /unigeek/games/stacker.txt.
