# Simon

The device plays a growing sequence of beeps on three coloured lanes. Repeat it back; survive as many rounds as you can.

## Controls

| Button | Action |
|--------|--------|
| UP | red lane    (top) |
| OK | blue lane   (middle) |
| DOWN | green lane  (bottom) |
| BACK | exit (also dismisses Game Over) |

Each successful round adds one new step. Best round persists to /unigeek/games/simon.txt.
